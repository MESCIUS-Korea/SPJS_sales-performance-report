# SpreadJS 판매 실적 보고서 (Sales Performance Report)

SpreadJS를 활용하여 구현한 **판매 실적 보고서(Sales Performance Report) 샘플**입니다.

JavaScript 스프레드시트 컴포넌트인 **MESCIUS SpreadJS**를 사용하여 Excel과 유사한 형태의 판매 실적 보고서를 웹 애플리케이션에서 구현할 수 있습니다.

본 샘플에서는 판매 데이터를 기반으로 실적을 조회하고, 데이터를 시각화하여 웹 환경에서 판매 현황을 확인할 수 있는 보고서 화면을 구성합니다.

## 주요 기능

- SpreadJS 기반 웹 스프레드시트 구현
- 판매 실적 데이터 조회 및 표시
- Excel과 유사한 보고서 레이아웃 구성
- 수식 및 데이터 계산
- 차트를 이용한 판매 실적 시각화
- Excel 파일 가져오기 및 내보내기
- SpreadJS 파일(`.sjs`)을 이용한 보고서 저장 및 로드

## 샘플 파일

| 파일 | 설명 |
| --- | --- |
| `판매실적보고서.xlsx` | 판매 실적 보고서 Excel 템플릿 |
| `salesPerformanceReport.sjs` | SpreadJS에서 사용하는 판매 실적 보고서 파일 |
| `scheme.json` | 샘플에서 사용하는 데이터 스키마 |
| `샘플 코드` | SpreadJS를 이용하여 보고서를 구현하는 JavaScript 샘플 코드 |

## SpreadJS란?

**SpreadJS**는 웹 애플리케이션에서 Excel과 유사한 스프레드시트 기능을 구현할 수 있는 JavaScript 스프레드시트 컴포넌트입니다.

셀 편집, 수식, 차트, 테이블, 조건부 서식, Excel 파일 가져오기/내보내기 등 다양한 스프레드시트 기능을 제공하며, 웹 기반 업무 시스템에서 Excel 형태의 화면이나 보고서를 구현하는 데 사용할 수 있습니다.

판매 실적 보고서뿐만 아니라 다음과 같은 업무 시스템을 구현하는 데 활용할 수 있습니다.

- 판매 및 매출 실적 관리
- 예산 관리
- 재고 관리
- KPI 대시보드
- 경영 보고서
- 재무 보고서
- Excel 기반 업무 시스템의 웹 전환

## 판매 실적 보고서

이 샘플은 기존 Excel 기반의 판매 실적 보고서를 **SpreadJS 기반 웹 스프레드시트**로 구현하는 방법을 보여줍니다.

기존 Excel 보고서의 레이아웃과 계산 방식을 활용하면서 웹 애플리케이션에서 데이터를 조회하고 수정할 수 있으며, 수식과 차트를 이용하여 판매 실적을 분석하고 시각화할 수 있습니다.

이를 통해 기존 Excel 업무 프로세스를 웹 기반 시스템으로 전환하거나, 웹 애플리케이션에 Excel과 유사한 보고서 기능을 추가할 수 있습니다.
